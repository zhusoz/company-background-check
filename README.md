# company-background-check（公司背调）技能说明

本文档为 `company-background-check` 技能的中文说明，面向使用或维护该技能的用户。技能的实际执行指令以 `SKILL.md` 为准。

## 技能简介

该技能用于对**国内企业**做多维度背景调查（背调 / 背景调查），从公开可核验的信息出发，判断公司可靠性，并输出：

- 各维度得分与加权总分（0–100）
- 风险等级与标识（低 / 中 / 无法核实 / 高风险）
- 整体置信度
- 关键依据与待核实事项

## 何时触发

出现以下任一情况时适用：

- 用户提供公司名称（或统一社会信用代码等公司信息）并要求背调；
- 用户提到"背调""背景调查"等明确意图；
- 用户提供批量公司 Excel/CSV 名单。

示例提问：

- "帮我背调一下 XX 公司"
- "XX 公司靠不靠谱？"
- "这份名单里有 20 家公司，逐家做背景调查"

## 适用范围与边界

- 面向在中国大陆登记注册的国内企业。
- 不适用于对自然人（个人履历、学历、犯罪记录等）的背调。
- 只使用公开、合法、可核验的数据；不登录、不付费、不访问非公开渠道（除非用户已明确提供合法途径）。

## 评分模型（当前版本）

| 维度 | 权重 | 验证要点 |
| --- | --- | --- |
| 基础验证 | 16% | 公司是否存在、登记状态是否正常、社保参保人数 |
| 性质验证 | 24% | 公司是否做自有产品业务（自有产品自营 / 代工承接 / 外包用工型） |
| 业务验证 | 16% | 主营业务所处行业（朝阳 / 稳定 / 夕阳）与业务可持续性 |
| 业界评价 | 20% | 知乎、牛客、职友集、脉脉等平台上的员工、求职者与同行评价 |
| 风控验证 | 24% | 法律纠纷、劳动仲裁、行政处罚、执行 / 失信等负面记录 |

总分计算公式：

`总分 = 基础得分×0.16 + 性质得分×0.24 + 业务得分×0.16 + 业界评价得分×0.20 + 风控得分×0.24`

### 风险等级

| 分数范围 | 风险等级 | 标识 |
| --- | --- | --- |
| 80–100 | 低风险 | ✅ |
| 50–79 | 中风险 | ⚠️ |
| 20–49 | 无法核实 | ⚠️ |
| 0–19 | 高风险 | ❌ |

说明："20–49 无法核实"表示证据不足、无法定级，**不等于确认公司有问题**。

### 性质验证的三种业务形态

| 业务性质 | 系数 | 分项得分 |
| --- | --- | --- |
| 自有产品型（自主品牌、自主设计/生产/销售） | 1.0 | 100 |
| 代工承接型（OEM/ODM、贴牌、项目承接为主） | 0.8 | 80 |
| 外包用工型（人力外包、劳务派遣、劳务分包为主） | 0.6 | 60 |

混合经营按主导收入来源归类；无法判断时按 0.6–0.8 区间给分并标注"业务性质待确认"。

## 置信度机制

每个维度先评估结论的可信程度：

`维度置信度 = 数据源可靠性系数 × 验证深度系数`

整体置信度按同一组权重加权：

`整体置信度 = 基础置信度×0.16 + 性质置信度×0.24 + 业务置信度×0.16 + 业界评价置信度×0.20 + 风控置信度×0.24`

数据源可靠性由高到低大致为：官方一手数据（国家企业信用信息公示系统、信用中国、法院、市场监管等）＞主流企业信息平台（企查查、天眼查、爱企查等）＞权威媒体转载＞社区帖子与一般网页。

整体置信度低于 0.5，或任一关键维度无法核实时，结论必须标注"待补充核实"，不得直接给出确定性的低风险结论。

## 批量名单格式

必填列：

- `公司名称`

推荐补充列（有助于同名区分与判断业务性质）：

- `统一社会信用代码`
- `注册地 / 省市`
- `行业`
- `备注（如业务关系、经营模式）`

处理规则：

- 逐家完成五维核验；
- 结果写入**新文件**，不修改原文件；
- 追加列：总分、风险等级、标识、整体置信度、各维度得分、关键依据、待核实事项；
- 单元格无法解析或名单存在空行时，先提示用户再继续。

## 结果怎么读

- 分数只是风险参考，不是对公司的定性结论。
- "未检索到记录"不等于"已核实无风险"，结论会随查询日期变化。
- 业界口碑类平台（知乎、牛客、职友集、脉脉）帖子多为匿名或情绪化内容，只能作为辅助线索；严重负面指控需用裁判文书、劳动仲裁、官方记录交叉验证。
- 同名公司很多，务必用统一社会信用代码或注册地确认主体，防止串户。
- 参保人数为 0 或缺失可能是新设公司、个体经营、统计口径等原因，需提示核实而非直接定性为空壳。
