# 公司背调（Company Background Check）

## 目标与适用场景

对国内目标公司从多个维度核验公开信息并打分，判断其可靠性，输出明确的风险结论、依据与置信度。本技能面向在中国大陆登记注册的国内企业。适用于：

- 用户提供公司名称（或统一社会信用代码等公司信息）并要求背调；
- 用户提到"背调""背景调查"等明确意图；
- 用户提供批量公司 Excel/CSV 文件。

不适用于对自然人（个人履历、学历、犯罪记录等）的背调；遇到此类请求应明确告知不在本技能范围内。

## 评分模型

### 维度与权重

| 维度 | 权重 | 验证要点 |
| --- | --- | --- |
| 基础验证 | 16% | 公司是否存在、登记状态是否正常、社保参保人数 |
| 性质验证 | 24% | 公司是否做自有产品业务（自有产品自营 / 代工承接 / 外包用工型） |
| 业务验证 | 16% | 主营业务所处行业（朝阳 / 稳定 / 夕阳）与业务可持续性 |
| 业界评价 | 20% | 知乎、牛客、职友集、脉脉等平台上的员工、求职者与同行评价 |
| 风控验证 | 24% | 法律纠纷、劳动仲裁、行政处罚、执行 / 失信等负面记录 |

每个维度先得出 0–100 的分项得分，然后加权汇总：

`总分 = 基础得分×0.16 + 性质得分×0.24 + 业务得分×0.16 + 业界评价得分×0.20 + 风控得分×0.24`

### 风险等级

| 分数范围 | 风险等级 | 标识 |
| --- | --- | --- |
| 80–100 | 低风险 | ✅ |
| 50–79 | 中风险 | ⚠️ |
| 20–49 | 无法核实 | ⚠️ |
| 0–19 | 高风险 | ❌ |

总分落在"无法核实"区间时，除分数外还要列出哪些维度缺少可核验证据；不要把"分数低"与"确认有问题"混为一谈。

### 分维度打分指引

下列区间为默认参考，可结合证据质量在区间内微调，但必须在结论中说明取值理由。

**基础验证（16%）**

- 工商登记存在、状态为存续/在业，社保参保人数可查且与公司规模相符：80–100。
- 公司存在但关键信息不全（参保人数缺失或显示为 0、平台数据滞后等）：40–79，并列入待核实事项。
- 查无登记，或状态为注销/吊销、被列入经营异常名录/严重违法失信名单：0–30；证据确凿且情形严重时低于 20。

**性质验证（24%）**

判断公司主业是否为"自有产品业务"：即拥有自主品牌或自有产品并自主设计、生产、经营，而非主要靠代工贴牌、承接项目或外包劳务生存。分项得分 = 100 × 业务性质系数：

| 业务性质 | 典型特征 | 系数 | 分项得分 |
| --- | --- | --- |
| 自有产品型 | 有自主品牌/自有产品线，自主研发、生产或销售，直接面向市场经营 | 1.0 | 100 |
| 代工承接型 | 以 OEM/ODM 代工、贴牌生产、项目承接、服务交付为主，自有产品占比低 | 0.8 | 80 |
| 外包用工型 | 基本无自有产品或业务实体，以人力资源外包、劳务派遣、劳务分包等为主要模式 | 0.6 | 60 |

判断依据：经营范围、官网与自主品牌信息、招聘岗位结构、工商与年报披露（如有）、媒体与行业资料，以及用户给出的业务关系。混合经营的公司按主导收入来源归类；无法判断时不要强行打分，按 0.6–0.8 对应区间给分并把"业务性质待确认"列为待核实事项。

**业务验证（16%）**

- 朝阳/成长行业，且有政策、行业或经营证据支持：80–100。
- 成熟稳定行业、经营信号正常：60–79。
- 明显衰退/夕阳行业，或主营与行业景气严重背离且缺乏转型证据：0–59。

行业判断要有依据（行业报告、政策文件、公开新闻、经营与招聘信号），避免凭印象下结论。

**业界评价（20%）**

检索知乎、牛客、职友集、脉脉等平台中与目标公司相关的帖子与点评（可补充看准网、本地论坛、招聘平台评价等），评估员工、求职者与同行的口碑：

- 多平台整体评价正面或中性，负面多为情绪化表述且无具体事实指控：80–100。
- 评价分化，存在关于加班、管理、薪资等常见吐槽，但无欠薪、裁员、经营恶化等系统性负面：60–79。
- 多个平台近期持续出现欠薪、强制裁员、劳动纠纷或经营困难等具体负面描述：40–59。
- 普遍且具体的严重负面（大规模欠薪、集体仲裁、经营暴雷等）：0–39。
- 几乎查不到有效评价：不能当作正面依据，给 20–49 并标注"公开评价缺失"，同时把该维度置信度压到最低。

平台帖子属于用户生成内容：可靠系数默认按 0.3–0.5 处理；多条独立帖子交叉印证、指控具体且时间较新时可适当上调，但严重指控必须与裁判文书、劳动仲裁、官方记录交叉验证后才能采信。

**风控验证（24%）**

- 在裁判文书、执行信息、信用中国、行政处罚、劳动仲裁公开信息、媒体等多源检索后无负面发现：80–100，但"未检索到"不等于"已核实无风险"，取分与结论都应留有余地。
- 存在少量历史纠纷且已了结、影响有限：60–79。
- 存在近期劳动仲裁、小额纠纷或经营异常记录：40–59。
- 存在未决重大诉讼、执行案件、行政处罚或失信记录：0–39，严重者 0–19。

## 置信度

每个维度的置信度衡量"该维度结论有多可信"：

`维度置信度 = 数据源可靠性系数 × 验证深度系数`

**数据源可靠性系数**

| 系数 | 数据源类型 |
| --- | --- |
| 1.0 | 官方一手数据：国家企业信用信息公示系统(gsxt.gov.cn)、信用中国(creditchina.gov.cn)、市场监管、法院、人社等官方渠道 |
| 0.8–0.9 | 主流第三方企业信息平台：企查查、天眼查、爱企查等 |
| 0.6–0.7 | 权威媒体或官方公告的可靠转载 |
| 0.3–0.5 | 一般网页、知乎/牛客/职友集/脉脉等社区帖子、招聘平台、用户提供的未经核验信息 |
| 0 | 无来源或来源不可用 |

**验证深度系数**

| 系数 | 验证深度 |
| --- | --- |
| 1.0 | 官方原始记录核验，或多源交叉核验一致 |
| 0.7 | 单一可靠来源核验 |
| 0.4 | 仅有二手聚合信息、无法回源 |
| 0.1–0.3 | 推断、信息陈旧或没有直接证据 |

`整体置信度 = 基础置信度×0.16 + 性质置信度×0.24 + 业务置信度×0.16 + 业界评价置信度×0.20 + 风控置信度×0.24`

整体置信度低（如低于 0.5）或任一关键维度无法核实时，结论必须标注"待补充核实"并列出缺口，不得直接给出确定性的低风险结论。

## 工作流程

1. **确认输入**：拿到公司名称；尽量补充统一社会信用代码、注册地、行业以及公司与调查方的关系和经营模式（用于业务性质判断与同名区分）。信息不足时先做初步核验，再把需要用户补充的字段列成清单。
2. **单家调查**：按五个维度逐项核验，为每条结论记录数据源、查询日期和可靠系数；据此打分并计算总分、风险等级与置信度。
3. **批量调查**：读取 Excel/CSV 名单，识别"公司名称"列（可支持统一社会信用代码、地区、行业等附加列）；逐家完成同样核验；将结果写入**新文件**，不修改原文件，追加列：总分、风险等级、标识、整体置信度、各维度得分、关键依据、待核实事项。发现无法解析的单元格或空行时先提示用户。
4. **输出**：单家调查给各维度得分、主要依据、待核实事项与最终结论；批量调查给汇总表，可按用户需要附加风险分布等统计。

## 边界与注意事项

- 只使用公开、合法、可核验的数据；不要使用需要登录、付费或非公开的渠道，除非用户已明确提供合法访问途径。
- 工商状态、参保人数、涉诉信息都会随时间变化，结论必须标注查询日期。
- 同名公司很多，务必用统一社会信用代码或注册地等区分，防止串户。
- 知乎/牛客/职友集/脉脉等平台帖子多为匿名、情绪化或带商业目的的内容，只能作为辅助线索；引用前先确认帖子针对的是同一主体，负面指控需用官方记录复核。
- 参保人数为 0 或缺失可能源于新设公司、个体经营、统计口径等原因，没有其他佐证时提示待核实，不要直接定性为空壳。
- 本技能输出是风险参考，不构成法律或投资建议；最终决策由用户判断。
